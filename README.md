# মেডিসেবা — ডাক্তার চেম্বার ও পেশেন্ট ম্যানেজমেন্ট

পাবলিক ওয়েবসাইট + ডাক্তার প্যানেল একসাথে। PHP ৮, MySQL বা SQLite। cPanel shared hosting-এ সরাসরি আপলোড।

## কী করে
- রোগী ওয়েবসাইট থেকে সিরিয়াল নেয়
- চেম্বার শুরুর সময় থেকে প্রতিজন ১৫–২০ মিনিট স্লট (২:০০, ২:২০, ২:৪০…)
- বুকিং ও দেরি রি-শিডিউলে বাংলা SMS
- ফোন নম্বর দিয়ে রোগী চেনা, হিস্ট্রি ও প্রেসক্রিপশন
- ডাক্তার ওয়েব থেকে প্রেসক্রিপশন লিখে প্রিন্ট

## cPanel-এ হোস্ট

1. cPanel → MySQL Database: ডাটাবেস, ইউজার, পাসওয়ার্ড তৈরি করে ইউজারকে ডাটাবেসে অ্যাড করুন।
2. সব ফাইল `public_html` (বা সাবডোমেইন ফোল্ডারে) আপলোড করুন।
3. `data` এবং `uploads` ফোল্ডার পারমিশন 0755 রাখুন।
4. ব্রাউজারে খুলুন: `https://yourdomain.com/install.php`
5. MySQL বেছে হোস্ট `localhost`, ডাটাবেস নাম, ইউজার, পাসওয়ার্ড দিন।
6. ডাক্তারের ফোন ও পাসওয়ার্ড সেট করুন। ইনস্টল শেষে `install.php` ডিলিট করতে পারেন।
7. Cron (প্রতি ৫ মিনিট):
   `php /home/USER/public_html/cron-remind.php`
   অথবা URL: `https://yourdomain.com/api/remind.php?key=YOURKEY`

SQLite চাইলে ইনস্টলারে SQLite সিলেক্ট করুন — আলাদা ডাটাবেস লাগবে না। `data/` রাইটেবল হতে হবে।

## ডিফল্ট লগইন (ইনস্টলের সময় না বদলালে)
- ফোন: `01700000000`
- পাসওয়ার্ড: `admin123`
- লগইন: `/doctor/login.php`

## এসএমএস
সেটিংস → এসএমএস। প্রথমে “শুধু লগ” মোডে টেস্ট করুন। পরে BulkSMSBD বা অন্য API URL/কি দিন।

## ফোল্ডার
- `/` পাবলিক সাইট
- `/doctor` ম্যানেজমেন্ট
- `/display.php` ওয়েটিং রুম TV
- `/docs` গাইড ও AI প্রম্পট

বিস্তারিত: `docs/SYSTEM_GUIDE.html` (প্রিন্ট করে PDF করা যায়) এবং `docs/AI_PROMPT.md`।
