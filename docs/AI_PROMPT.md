# AI Prompt — Doctor Patient Management System (cPanel)

নিচের প্রম্পটটি কোনো AI কোডিং এজেন্টে পেস্ট করুন। সিস্টেম PHP + MySQL, cPanel shared hosting-এ চলবে।

---

আমাকে একটি সম্পূর্ণ Doctor Chamber Patient Management System বানিয়ে দাও — পাবলিক ওয়েবসাইট + ডাক্তার ম্যানেজমেন্ট প্যানেল একসাথে। Shared hosting / cPanel-এ আপলোড করে চালু করতে পারব (PHP 8+, MySQL/MariaDB)। Node.js বা আলাদা সার্ভার লাগবে না।

## ভাষা ও ব্র্যান্ড
- UI বাংলা (Hind Siliguri ফন্ট), মেডিকেল গ্রিন টোন।
- ক্লিনিকের নাম, ঠিকানা, ফোন, ডাক্তারের নাম ইনস্টলার ও সেটিংস থেকে বদলানো যাবে।

## মূল সমস্যা যা সমাধান করতে হবে
রোগীরা সিরিয়াল নিয়ে সকাল থেকে বসে থাকে। চাই:
1. ওয়েবসাইট থেকে অ্যাপয়েন্টমেন্ট।
2. ডাক্তার নিজে চেম্বারের সময় কাস্টম আপডেট করবেন।
3. সেই শুরুর সময় থেকে প্রতি রোগী ১৫–২০ মিনিট স্লট। উদাহরণ: প্রথম ২:০০, পরেরটি ২:২০, তারপর ২:৪০।
4. যারা বুক করবে তাদের SMS যাবে: “আপনার অ্যাপয়েন্টমেন্ট ২:০০ থেকে”। সিরিয়াল ৫০ হলেও রোগী নিজের মেসেজের সময়ে আসবে — আগে এসে বসে থাকতে হবে না।
5. ডাক্তার ১ ঘণ্টা দেরি করলে সব সিরিয়াল অটো রি-শিডিউল + সবাইকে নতুন সময় SMS।
6. ডাক্তার ওয়েবসাইট থেকেই প্রেসক্রিপশন লিখবেন, প্রিন্ট হবে।
7. রোগী আইডেন্টিটি মোবাইল নম্বর। পরেরবার শুধু নম্বর দিলেই ডাক্তার পুরো হিস্ট্রি দেখবেন; রোগীও ওয়েবসাইট থেকে প্রেসক্রিপশন দেখতে পারবেন।

## মডিউল

### A. পাবলিক ওয়েবসাইট
- হোম: ডাক্তার পরিচিতি, আজকের চেম্বার, ফাঁকা সিরিয়াল, দেরি অ্যালার্ট, আসন্ন দিন।
- সিরিয়াল পেজ: তারিখ চিপ, ফাঁকা স্লট রেডিও, নাম/ফোন/বয়স/লিঙ্গ।
- টিকিট: সিরিয়াল, বাংলা তারিখ-সময়, পোর্টাল পিন, প্রিন্ট।
- স্ট্যাটাস: ফোন দিয়ে খোঁজা, এখন চেম্বারে কোন সিরিয়াল, দেরি নোটিশ।
- রোগী পোর্টাল: ফোন + ৪ অঙ্কের পিন, প্রেসক্রিপশন লিস্ট ও প্রিন্ট।
- অ্যাবাউট: সাপ্তাহিক সময়সূচি।

### B. ডাক্তার প্যানেল (ফোন+পাসওয়ার্ড)
- ড্যাশবোর্ড: আজকের কাউন্ট, দেরি ফর্ম (মিনিট + কারণ → সব booked/waiting রি-শিডিউল + SMS)।
- কিউ: চেক-ইন / চেম্বারে / সম্পন্ন / আসেননি / বাতিল। বাতিল হলে SMS। অটো রিফ্রেশ।
- প্রেসক্রিপশন: C/C, O/E, Dx, ওষুধ সারি (নাম, মাত্রা, মেয়াদ, নির্দেশ), টেমপ্লেট চিপ, টেস্ট, অ্যাডভাইস, ফলো-আপ। সেভ করলে প্রিন্ট পেজ (℞ লেআউট)। স্ট্যাটাস done।
- সময়সূচি: সপ্তাহের দিন অনুযায়ী শুরু-শেষ, স্লট মিনিট, সর্বোচ্চ সিরিয়াল, অন/অফ। বিশেষ দিন বা ছুটি।
- রোগী সার্চ: ফোন/নাম। ফাইলে হিস্ট্রি + সব প্রেসক্রিপশন।
- ওয়াক-ইন বুকিং (চেম্বার রিসেপশন)।
- SMS সেটিংস: log মোড বা HTTP API (URL, key, sender, GET/POST)। বাংলাদেশি গেটওয়ে যেমন BulkSMSBD। টেস্ট বাটন ও লগ।
- ক্লিনিক/প্রোফাইল সেটিংস।

### C. অ্যাপয়েন্টমেন্ট ইঞ্জিন (বাধ্যতামূলক লজিক)
- schedule_for_date: আগে exception (ছুটি/বিশেষ), নাহলে weekday schedule।
- generate_slots: start_time থেকে end_time, প্রতি slot_minutes, max_serial। current_delay যোগ করে scheduled_time। original_time আলাদা রাখবে যাতে দেরি বদলালে আসল সময় থেকে নতুন করে হিসাব হয়।
- একই ফোন + একই তারিখে ডুপ্লিকেট বুকিং বন্ধ।
- অতীত তারিখ বন্ধ। চেম্বার নেই দিন বন্ধ।
- apply_delay(date, minutes): delays টেবিল, সব অ্যাপয়েন্টমেন্টের scheduled_time = original_time + delay, SMS reschedule।

SMS টেমপ্লেট বাংলায়:
- বুকিং: ক্লিনিক, নাম, সিরিয়াল, তারিখ, সময়, ডাক্তার, “সময়মতো আসুন, বেশি আগে এসে অপেক্ষা করবেন না”
- রি-শিডিউল: কত মিনিট দেরি, নতুন সময়
- রিমাইন্ডার: পালা আসছে, রওনা দিন
- বাতিল

### D. রোগী আইডেন্টিটি
- ফোন নর্মালাইজ: 01XXXXXXXXX (8801… → 01…)
- না থাকলে পেশেন্ট তৈরি + র্যান্ডম ৪ ডিজিট পিন
- থাকলে নাম/বয়স আপডেট, পুরনো হিস্ট্রি জুড়ে থাকবে
